# OpenMautoTest 开发阶段指导书（第2部分：阶段6-10）

本文档定义了OpenMautoTest项目的后5个开发阶段（第6-10阶段）。每个阶段必须按顺序完成，完成当前阶段所有目标并记录开发日志后，方可进入下一阶段。

---

## 阶段6：业务流程和测试用例实现

### 开发任务
1. **测试流程框架开发**
   - 实现`orchestrator/flow_runner.py`流程执行引擎
   - 支持跨端流程编排和步骤间数据传递
   - 实现流程执行的状态管理和异常处理

2. **业务流程实现**
   - 在`flows/login_and_buy/`目录下实现登录购买流程
   - 开发`web_steps.py`Web端业务步骤封装
   - 开发`mini_steps.py`小程序端业务步骤封装
   - 创建`test_flow.py`端到端测试用例

3. **pytest配置优化**
   - 配置`flows/conftest.py`流程级别的fixtures
   - 实现测试用例发现和执行机制
   - 支持通过标签过滤和参数化执行

### 阶段目标
- 完整的流程执行引擎已实现
- 至少一个完整的业务流程可以正常执行
- 测试用例可以通过pytest正常运行
- 支持Web端和小程序端的协同测试

### 必带的额外目标说明
- **前后端接口检查**：仔细验证业务流程中涉及的所有API调用，确保请求参数、响应格式与后端接口一致
- **程序运行检查**：完整的业务流程可以端到端执行，pytest可以发现并运行测试用例，无运行时错误
- **代码文件行数控制**：每个步骤文件不超过500行，复杂业务流程拆分为多个步骤文件
- **数据流转机制**：通过pytest hooks(pytest_runtest_*)收集测试执行数据，在conftest.py中配置全局fixture触发数据记录

### 完成标准
- [ ] 流程执行引擎功能完整且稳定
- [ ] 登录购买流程可以端到端执行成功
- [ ] pytest可以正常发现和执行测试用例
- [ ] Web端和小程序端步骤可以正常协作
- [ ] 流程执行过程中的数据传递正常

## 阶段9：数据可视化和Metabase集成

### 开发任务
1. **Metabase环境搭建**
   - 完善`docker-compose.meta.yml`配置
   - 创建`metabase/Dockerfile-meta`定制镜像
   - 配置Metabase与PostgreSQL的连接

2. **数据库查询开发**
   - 在`metabase/sql/`目录下创建6个核心指标查询SQL：
     - daily_trend.sql: 历史自动化执行总数(KPI)
     - pass_rate.sql: 历次自动化执行的测试用例数(趋势图)
     - avg_duration.sql: 测试用例成功率(趋势图/饼图)
     - task_duration.sql: 单次任务总耗时(趋势图)
     - saved_time.sql: 节省人时累计曲线(面积图)
     - failed_cases_top10.sql: 失败用例TOP10(横向条形图)

3. **仪表盘配置**
   - 创建`metabase/init/automationOS_dashboard.json`仪表盘定义
   - 配置“质量核心看板”仪表盘，包含6个核心指标的图表展示：
     - 历史自动化执行总数(KPI)
     - 历次自动化执行的测试用例数(趋势图)
     - 测试用例成功率(趋势图/饼图)
     - 单次任务总耗时(趋势图)
     - 节省人时累计曲线(面积图)
     - 失败用例TOP10(横向条形图)
   - 实现仪表盘的自动化导入和初始化

4. **数据管道验证**
   - 验证从测试执行到数据展示的完整数据流
   - 确保数据实时性和准确性
   - 实现数据质量监控和告警

### 阶段目标
- Metabase数据可视化平台正常运行
- 6个核心指标仪表盘功能完整
- 数据从执行到展示的全链路正常
- 数据质量和实时性满足需求

### 必带的额外目标说明
- **前后端接口检查**：确保Metabase连接数据库的配置正确，SQL查询能够正确访问数据表
- **程序运行检查**：Metabase服务可以正常启动，仪表盘可以正确显示数据，图表渲染正常
- **代码文件行数控制**：SQL查询文件保持简洁，复杂查询拆分为多个视图或函数

### 完成标准
- [ ] Metabase服务可以正常启动和访问
- [ ] 数据库连接配置正确且稳定
- [ ] 所有6个核心指标图表正常显示
- [ ] 仪表盘可以自动初始化和导入
- [ ] 数据更新及时且准确
