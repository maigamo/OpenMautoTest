技术栈与版本规范
以下是项目选定的技术栈及其兼容版本。选择这些版本是为了在功能先进性与长期稳定性之间取得平衡。

组件分类	技术/库名称	指定版本	理由与兼容性说明
运行环境	Python	3.10.x	这是一个成熟且广泛支持的 Python 版本，兼顾了新特性和库的兼容性。
数据库	PostgreSQL	15.x	最新主要的稳定版本，提供卓越的性能，并被 Metabase 和 SQLAlchemy 2.0 完美支持。
CI/CD & 容器化	Jenkins	LTS 2.414.x	选择长期支持版（LTS）以获得最高的稳定性。
Docker Engine	24.x	确保能够使用最新的容器化特性和安全更新。
Docker Compose	v2.20.x	使用 V2 版本的 Compose 语法，集成度更高。
数据可视化	Metabase	v0.49.x	最新稳定版本，确保与 PostgreSQL 15 兼容，并拥有最新的图表功能和安全修复。
测试框架	pytest	7.4.x	主流的测试执行引擎，社区活跃，插件丰富。
pytest-xdist	3.5.x	用于并行执行测试，与 pytest 7.4.x 兼容。
Web 自动化	playwright	1.40.x	Playwright Python 库，版本需与 playwright install 安装的浏览器驱动版本匹配。
DB & ORM	SQLAlchemy	2.0.x	ORM 核心，2.0 版本带来了现代化的 API 和性能提升，是新项目的首选。
Alembic	1.12.x	数据库迁移工具，与 SQLAlchemy 2.0 完全兼容。
psycopg2-binary	2.9.x	Python 连接 PostgreSQL 的驱动程序，性能可靠。
报告生成	allure-pytest	2.13.x	Allure 报告生成插件，与 pytest 7.4.x 兼容良好。
配置管理	python-dotenv	1.0.x	用于从 .env 文件加载环境变量。
代码质量	black	24.x	强制代码格式化工具，确保代码风格绝对一致。
ruff	0.1.x	高性能代码检查工具，集成了 flake8, isort, pyupgrade 等多种工具的功能。
