OpenMautoTest UI 风格设计文档 (V1.0)
1. 设计哲学
OpenMautoTest 的 UI 设计核心是 “洞察力驱动” (Insight-Driven)。所有设计元素都应服务于一个目标：帮助用户快速、准确地理解自动化测试数据，定位问题并衡量效益。我们追求清晰、高效、一致的视觉语言，避免不必要的装饰。

2. 参考设计系统
主参考：Vercel Analytics

我们将借鉴其现代、简洁的设计风格，特别是在色彩、布局和数据可视化方面的最佳实践。

3. 色彩规范 (Color Palette)
我们将采用以暗色为基础的调色板，这有助于降低屏幕眩光，并让数据图表中的语义化颜色更醒目。

4. 排版规范 (Typography)
选择一款现代、清晰的无衬线字体，以保证在数字和文本混排时的可读性。

主字体 (Font Family): Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif。

说明: 优先使用 Inter 字体（需 WebFont 引入），它专为 UI 设计，清晰度极高。如果无法加载，则依次优雅降级为系统默认字体。

字号层级 (Font Scale):

看板标题 (H1): 24px, Bold

图表/卡片标题 (H2): 18px, Medium

KPI 数字: 36px, Bold

正文/表格内容: 14px, Regular

辅助/标签文字: 12px, Regular

5. 布局与间距 (Layout & Spacing)
栅格系统: 整个仪表盘（Dashboard）应基于 12 列栅格系统构建，确保卡片布局的灵活性和对齐。

基础间距单位: 8px。项目所有的 padding, margin, gap 都应是 8px 的倍数 (e.g., 8px, 16px, 24px, 32px)。

卡片内部 padding: 16px 或 24px。

卡片之间 gap: 16px。

页面左右 margin: 24px。

6. 组件风格 (Components)
6.1 卡片 (Card / Widget)
背景: 使用 Surface 色 (#111111)。

边框: 1px 实线，使用 Border 色 (#333333)。

圆角 (Border Radius): 8px，营造柔和现代的观感。

标题: 左上角放置卡片标题（H2 样式），清晰说明图表内容。

6.2 图表 (Charts & Graphs)
风格: 保持极简，移除所有不必要的视觉元素，如图表背景网格线（除非必要）。

坐标轴: 使用 Secondary Text 色，字号为 12px。

工具提示 (Tooltip): 当鼠标悬停在数据点上时，显示一个深色背景、信息清晰的 Tooltip。Tooltip 应包含数据系列名称、确切值和时间点。

面积图 (Area Chart): 如图“节省人时累计曲线”，使用从 Information 色 (#007BFF) 到透明的渐变填充，突出趋势感。

条形图 (Bar Chart): 如图“失败用例 TOP10”，使用 Failure 色 (#DC3545)，条形之间有足够间距。

6.3 表格 (Table)
表头: 字体加粗，背景色可略深于内容行，以作区分。

行: 无需斑马条纹，通过足够的行高和清晰的分割线 (Border 色) 保证可读性。

交互: 鼠标悬停在行上时，应有背景高亮效果。

7. 图标 (Iconography)
风格: 线性、极简。

推荐库: Feather Icons 或 Heroicons。它们的风格现代、一致，非常适合用在技术产品中。

用法: 用于按钮、状态指示等，作为文字的视觉辅助。

8. 交互反馈 (Interactivity)
悬停 (Hover): 所有可点击的元素（链接、按钮、图表数据系列）在鼠标悬停时都应有明确的视觉变化，如颜色变亮或出现下划线。

加载 (Loading): 当卡片内的数据正在加载时，应显示一个优雅的加载指示器（如骨架屏 Skeleton 或旋转动画），而不是空白。
