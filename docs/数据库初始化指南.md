## 环境要求

### 必需组件

- **PostgreSQL 12+**: 主数据库，存储测试执行记录
- **Python 3.8+**: 运行环境
- **SQLAlchemy 1.4+**: ORM框架
- **Alembic**: 数据库迁移工具

### 可选组件

- **MongoDB 4.4+**: 日志存储（可选）
- **Redis 6.0+**: 缓存和会话存储（可选）

### Python依赖

确保已安装以下Python包：

```bash
pip install sqlalchemy psycopg2-binary alembic pyyaml
```

## 数据库配置

### 配置文件位置

数据库配置位于 `configs/db.yaml` 文件中，支持多环境配置。

### 配置结构

```yaml
# 开发环境配置
development:
  postgresql:
    host: localhost
    port: 5432
    database: openmautotest_dev
    username: postgres
    password: ""
    pool_size: 10
    max_overflow: 20
    pool_timeout: 30
    pool_recycle: 3600
```

### 环境变量支持

配置文件支持环境变量替换，格式如下：

```yaml
production:
  postgresql:
    host: ${DB_HOST}
    port: ${DB_PORT:5432}
    database: ${DB_NAME}
    username: ${DB_USER}
    password: ${DB_PASSWORD}
```

### 配置验证

使用以下命令验证数据库配置：

```bash
python -c "from configs.db import check_db_config; check_db_config()"
```

## 初始化方法

### 方法一：使用初始化脚本（推荐）

项目提供了专门的数据库初始化脚本：

```bash
# 进入项目根目录
cd /path/to/OpenMautoTest

# 运行初始化脚本
python db/scripts/init_database.py
```

该脚本会自动执行以下操作：

1. 检查数据库配置
2. 创建数据库（如果不存在）
3. 创建表结构
4. 创建索引
5. 验证初始化结果

### 方法二：使用Alembic迁移

如果需要使用Alembic进行更精细的迁移控制：

```bash
# 运行迁移脚本
python db/scripts/run_migrations.py upgrade

# 或者直接使用alembic命令
python -m alembic upgrade head
```

### 方法三：手动初始化

在Python代码中手动初始化：

```python
from sqlalchemy import create_engine
from db.models import Base
from configs.db import get_db_config

# 获取数据库配置
db_config = get_db_config()
engine = db_config.create_postgresql_engine()

# 创建所有表
Base.metadata.create_all(bind=engine)
```

## 表结构说明

### 主要数据表

#### 1. test_case_runs（测试用例执行记录表）

存储每次测试用例的执行记录。

**主要字段：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增ID |
| run_id | VARCHAR(255) | 单次任务ID |
| project_name | VARCHAR(100) | 项目名称 |
| flow_name | VARCHAR(255) | 业务流程名称 |
| test_case_name | TEXT | 测试用例名称 |
| status | VARCHAR(20) | 执行状态（passed/failed/skipped） |
| environment | VARCHAR(50) | 测试环境 |
| start_time | TIMESTAMP | 开始时间 |
| end_time | TIMESTAMP | 结束时间 |
| duration | FLOAT | 执行耗时（秒） |
| failure_reason | TEXT | 失败原因 |
| error_details | JSONB | 详细错误信息 |

**索引：**

- `idx_run_id`: 运行ID索引
- `idx_project_flow`: 项目和流程复合索引
- `idx_status`: 状态索引
- `idx_start_time`: 开始时间索引
- `idx_environment`: 环境索引

#### 2. test_steps（测试步骤记录表）

存储测试用例的详细步骤信息。

**主要字段：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增ID |
| test_case_run_id | BIGINT | 关联的测试用例ID |
| step_name | VARCHAR(255) | 步骤名称 |
| step_order | INTEGER | 步骤顺序 |
| status | VARCHAR(20) | 步骤状态 |
| start_time | TIMESTAMP | 开始时间 |
| duration | FLOAT | 执行耗时（秒） |
| error_message | TEXT | 错误消息 |

#### 3. test_run_summaries（测试运行汇总表）

存储每次测试运行的汇总信息。

**主要字段：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增ID |
| run_id | VARCHAR(255) | 运行ID（唯一） |
| run_name | VARCHAR(255) | 运行名称 |
| total_tests | INTEGER | 总测试数 |
| passed_tests | INTEGER | 通过测试数 |
| failed_tests | INTEGER | 失败测试数 |
| pass_rate | FLOAT | 通过率 |

### 约束条件

#### 检查约束

- 状态值限制：`status IN ('passed', 'failed', 'skipped', 'running', 'pending')`
- 时间非负：`duration >= 0`
- 重试次数非负：`retry_attempt >= 0`
- 通过率范围：`pass_rate >= 0 AND pass_rate <= 100`

#### 外键约束

- `test_steps.test_case_run_id` → `test_case_runs.id` (CASCADE DELETE)

## 迁移管理

### Alembic配置

Alembic配置文件位于 `db/migrations/alembic.ini`，主要配置：

```ini
[alembic]
script_location = db/migrations
file_template = %%(year)d%%(month).2d%%(day).2d_%%(hour).2d%%(minute).2d_%%(rev)s_%%(slug)s
timezone = UTC
```

### 常用迁移命令

#### 查看当前版本

```bash
python db/scripts/run_migrations.py current
```

#### 查看迁移历史

```bash
python db/scripts/run_migrations.py history
```

#### 升级到最新版本

```bash
python db/scripts/run_migrations.py upgrade
```

#### 升级到指定版本

```bash
python db/scripts/run_migrations.py upgrade 001
```

#### 降级到指定版本

```bash
python db/scripts/run_migrations.py downgrade 001
```

#### 生成新的迁移文件

```bash
python db/scripts/run_migrations.py generate "add new column"
```

### 迁移文件结构

迁移文件位于 `db/migrations/versions/` 目录，命名格式：

```
YYYYMMDD_HHMM_revision_description.py
```

例如：`20250926_1200_001_init_automationos.py`

## 常见问题

### 问题1：连接错误 "Not an executable object: 'SELECT 1'"

**原因：** SQLAlchemy 2.0+ 版本要求使用 `text()` 函数包装字符串SQL。

**解决方案：**

```python
# 错误写法
conn.execute("SELECT 1")

# 正确写法
from sqlalchemy import text
conn.execute(text("SELECT 1"))
```

### 问题2：表不存在错误 "relation 'test_case_runs' does not exist"

**原因：** 数据库表尚未创建。

**解决方案：**

```bash
# 运行数据库初始化
python db/scripts/init_database.py

# 或者运行迁移
python db/scripts/run_migrations.py upgrade
```

### 问题3：数据库连接失败

**原因：** 数据库配置错误或数据库服务未启动。

**检查步骤：**

1. 确认PostgreSQL服务已启动
2. 检查数据库配置文件 `configs/db.yaml`
3. 验证数据库用户权限
4. 测试网络连接

**验证命令：**

```bash
# 测试数据库连接
psql -h localhost -p 5432 -U postgres -d openmautotest_dev

# 验证配置
python -c "from configs.db import check_db_config; check_db_config()"
```

### 问题4：权限不足

**错误信息：** `permission denied to create database`

**解决方案：**

1. 确保数据库用户具有创建数据库的权限：

```sql
ALTER USER postgres CREATEDB;
```

2. 或者手动创建数据库：

```sql
CREATE DATABASE openmautotest_dev;
```

### 问题5：编码问题

**错误信息：** `invalid byte sequence for encoding "UTF8"`

**解决方案：**

1. 创建数据库时指定编码：

```sql
CREATE DATABASE openmautotest_dev 
    WITH ENCODING 'UTF8' 
    LC_COLLATE='en_US.UTF-8' 
    LC_CTYPE='en_US.UTF-8';
```

2. 或者在连接URL中指定编码：

```yaml
postgresql:
  # ...
  options: "-c client_encoding=utf8"
```

```bash
pg_dump -h localhost -p 5432 -U postgres openmautotest_dev > backup.sql
```

#### 备份特定表

```bash
pg_dump -h localhost -p 5432 -U postgres -t test_case_runs openmautotest_dev > test_case_runs_backup.sql
```

### 数据恢复

```bash
psql -h localhost -p 5432 -U postgres openmautotest_dev < backup.sql
```

### 性能优化

#### 1. 定期更新统计信息

```sql
ANALYZE test_case_runs;
ANALYZE test_steps;
ANALYZE test_run_summaries;
```

#### 2. 重建索引

```sql
REINDEX TABLE test_case_runs;
```

#### 3. 清理过期数据

```sql
-- 删除90天前的测试记录
DELETE FROM test_case_runs 
WHERE start_time < NOW() - INTERVAL '90 days';
```

### 监控和日志

#### 1. 连接池监控

```python
from configs.db import get_db_config

db_config = get_db_config()
engine = db_config.create_postgresql_engine()

# 查看连接池状态
pool = engine.pool
print(f"Pool size: {pool.size()}")
print(f"Checked out connections: {pool.checkedout()}")
```

#### 2. 慢查询日志

在 `postgresql.conf` 中启用慢查询日志：

```ini
log_min_duration_statement = 1000  # 记录超过1秒的查询
log_statement = 'all'              # 记录所有语句
```

#### 3. 数据库大小监控

```sql
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) as size
FROM pg_tables 
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;
```

## 生产环境部署

### 1. 数据库服务器配置

#### PostgreSQL配置优化

编辑 `postgresql.conf`：

```ini
# 内存配置
shared_buffers = 256MB
effective_cache_size = 1GB
work_mem = 4MB

# 连接配置
max_connections = 200
listen_addresses = '*'

# 日志配置
log_destination = 'csvlog'
logging_collector = on
log_directory = 'log'
log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'
log_rotation_size = 100MB

# 性能配置
checkpoint_completion_target = 0.9
wal_buffers = 16MB
```

#### 安全配置

编辑 `pg_hba.conf`：

```ini
# 限制连接来源
host    openmautotest    postgres    10.0.0.0/8    md5
host    openmautotest    postgres    192.168.0.0/16    md5

# 拒绝其他连接
host    all    all    0.0.0.0/0    reject
```

### 2. 环境变量配置

创建 `.env` 文件：

```bash
# 数据库配置
DB_HOST=your-db-host
DB_PORT=5432
DB_NAME=openmautotest_prod
DB_USER=openmautotest_user
DB_PASSWORD=your-secure-password

# 环境标识
ENVIRONMENT=production
```

### 3. 部署脚本

创建部署脚本 `deploy_db.sh`：

```bash
#!/bin/bash

# 设置环境变量
export ENVIRONMENT=production

# 验证配置
echo "验证数据库配置..."
python -c "from configs.db import check_db_config; check_db_config()" || exit 1

# 备份现有数据库（如果存在）
echo "备份现有数据库..."
pg_dump -h $DB_HOST -p $DB_PORT -U $DB_USER $DB_NAME > backup_$(date +%Y%m%d_%H%M%S).sql

# 运行迁移
echo "运行数据库迁移..."
python db/scripts/run_migrations.py upgrade || exit 1

echo "数据库部署完成！"
```

## 故障排除

### 日志文件位置

- 应用日志：`output/logs/db_init.log`
- PostgreSQL日志：通常在 `/var/log/postgresql/` 或数据目录的 `log/` 子目录

### 诊断命令

```bash
# 检查PostgreSQL服务状态
sudo systemctl status postgresql

# 查看PostgreSQL进程
ps aux | grep postgres

# 检查端口占用
netstat -tlnp | grep 5432

# 测试数据库连接
python -c "
from configs.db import get_db_config
db_config = get_db_config()
engine = db_config.create_postgresql_engine()
with engine.connect() as conn:
    result = conn.execute('SELECT version()')
    print(result.fetchone()[0])
"
```

### 紧急恢复

如果数据库损坏，可以使用以下步骤恢复：

1. 停止应用程序
2. 备份当前数据库状态
3. 删除损坏的数据库
4. 从最新备份恢复
5. 重新运行迁移
6. 验证数据完整性

```bash
# 停止应用
sudo systemctl stop openmautotest

# 删除损坏的数据库
dropdb openmautotest_prod

# 从备份恢复
createdb openmautotest_prod
psql openmautotest_prod < latest_backup.sql

# 运行迁移
python db/scripts/run_migrations.py upgrade

# 启动应用
sudo systemctl start openmautotest
```
